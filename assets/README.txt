Save the THE VØID artwork in this folder as:

    banner.png

The project README references assets/banner.png at the top. Until that file
exists, GitHub renders a broken-image icon with the alt text "THE VØID".

If you would rather not use a banner image at all, delete the <img> line at the
top of README.md instead.

Recommended: around 1200px wide, PNG. GitHub scales it down to the 620px the
README requests, so a larger source stays sharp on high-DPI screens.
